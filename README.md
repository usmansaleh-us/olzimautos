# OLZIM AUTOS — BYD Customer Portal

This package refreshes the frontend only. The existing `backend/` folder is preserved unchanged.

## GitHub Pages
Upload these items directly into the repository root:

- `index.html`
- `app.js`
- `styles.css`
- `api.js`
- `admin.html`
- `assets/`
- `backend/` (kept for later backend deployment)

GitHub Pages serves the frontend files. The Node/Express backend must be deployed separately when you are ready to make accounts, appointments, quotes and service workflows fully live.

## Important
Vehicle images in `assets/` are local copies prepared from the supplied OLZIM AUTOS reference artwork so the GitHub Pages site does not depend on hot-linked image URLs.

Prices shown on the demo are the figures in the supplied reference design and are labelled as illustrative; confirm final prices with OLZIM AUTOS before publishing commercially.


## OLZIM AUTOS visual upgrade
The frontend now uses bundled local vehicle images, cinematic CSS graphics, hover effects, car float animation, light sweeps, reveal-on-scroll motion, pricing cards and responsive layouts. The backend folder is unchanged from the original project.
